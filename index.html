01 · Our Idea

What are we making?

The Basketball AI Shot Predictor uses a webcam to track the player's posture and the basketball. The system then calculates important features such as release angle, velocity and acceleration.

These values are analysed by a Random Forest model trained on previous shots to predict whether the shot will be a Make or Miss.

Our goal: use data from a basketball shot to understand shooting technique and predict the likely outcome of the shot.

Machine Learning

Random Forest is a machine learning algorithm used for classification and regression tasks. Instead of relying on one decision tree, it combines the predictions of many decision trees.

Each tree is trained using a random subset of the data and considers a random subset of features. This creates diversity between the trees and helps reduce overfitting and variance.

Features Analysed

The model can analyse features extracted from a shot, including:

  • Release angle
  • Velocity
  • Acceleration
  • Distance
  • Body-joint angles
